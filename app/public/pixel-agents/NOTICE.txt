Character artwork is based on MetroCity by JIK-A-4 (CC0):
https://jik-a-4.itch.io/metrocity-free-topdown-character-pack
Upstream character animation format: 112 x 96, seven 16 x 32 frames per
direction, rows down/up/right; frames 3-4 type, frames 5-6 read.

Furniture is from Pixel Agents' open-source bundle introduced in PR #117:
https://github.com/pixel-agents-hq/pixel-agents/pull/117
No proprietary Donarg tileset or Star Office UI assets are included.

Acedia provides its own host-state adapter, automatic room layout and renderer.
The upstream CLI, terminal, hook installer and agent server are not bundled.
