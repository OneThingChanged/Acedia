# Acedia 1.8.1.5

## Changes

- Settings → Agents now offers **Set as default** directly on Existing login
  and ready registered Codex/Claude accounts. Selection applies to new local
  sessions and synchronizes the account badge and defaults dropdown.
- Footer **Refresh** and **Refresh all accounts** in Agent usage retrieve quotas
  for every registered account, including idle and hidden accounts. Codex uses
  account-only app-server RPCs with isolated login environments; no model turn
  is started. Claude uses each account's OAuth usage request. Partial failures
  preserve cached usage and show login, timeout, failure or unavailable states.
- Desktop HTML previews no longer reject files larger than 2MB. The existing
  project-scoped streaming server serves large pages and relative assets inside
  the isolated browser. Remote document readers keep their own size limits.
- The terminal startup and configuration fixes committed in source 1.8.1.4 are
  included: unreadable or invalid settings are preserved, failed SSH preparation
  releases its reserved port, and shutdown invalidates pending launches.

See [account management](account-registration.md), [account quota behavior](properties-and-usage.md),
[HTML preview behavior](embedded-browser-mcp.md) and [the startup review](terminal-launch-review-2026-09-12.md).
