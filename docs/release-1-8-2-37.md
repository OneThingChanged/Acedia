# Acedia 1.8.2.37

- 한 프로젝트 보드에서 업무 보드, 계층, Pixel Office를 전환할 수 있습니다. 업무 보드에서 곡선과 직선 연결을 선택하고, 카드의 **계층 편집** 메뉴에서 부모·상속·참조 설정을 바로 열 수 있습니다.
- Remote 세션의 제목과 상태를 한 줄로 줄였습니다. 작업 경로, 상위 세션, 최근 작업 요청은 `⋯` 메뉴에서 확인할 수 있습니다.
- 모바일 Remote에서 첨부·입력·전송을 한 줄에 배치하고 하단 메뉴 높이를 줄였습니다.

## English

- Switch between Work board, Hierarchy, and Pixel Office in the same Project board. Choose curved or straight connections and open parent, inheritance, and reference settings from a card's **Edit hierarchy** menu.
- The Remote session title and status share one row. Open the `⋯` menu to see the working folder, parent sessions, and most recent work request.
- On mobile Remote, attachments, message entry, and Send share one row above a shorter navigation bar.
