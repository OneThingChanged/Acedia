# 데스크톱 새 세션 만들기

1. 사이드바에서 프로젝트를 선택하고 **새 세션**을 연다.
2. 별칭과 AI 도구를 고른다. 실행 옵션의 초기값은 설정에 저장된 도구별 기본값을 따른다.
   로컬 Codex·Claude 세션에 저장되거나 상속된 모델 설정이 없으면 **설정 → 에이전트 → 도구 → 기본 모델**에서 지정한 모델·effort를 사용한다. Codex는 Fast 기본값도 적용한다. [적용 순서와 초기값](agent-launch-options.md#acedia-기본-모델)을 참고한다.
3. 로컬 Codex·Claude 세션이면 로그인 계정을 선택한다. Codex 계정 분산이 등록되어 있으면 **분산 계정**도 표시한다. **자동 배정**은 세션 시작 시 계정을 배정하며, 특정 계정은 다음 시작부터 고정한다. 고정한 계정을 사용할 수 없으면 시작하지 않는다. 분산이 꺼진 경우에는 안내가 표시된다.
4. 필요한 경우 Dangerous 모드와 Codex의 Alt-screen 모드를 바꾼다.
5. 실행 경로·추가 인수·환경변수가 필요하면 아래 **고급 실행 설정**을 펼친다. 잘못된 고급 설정은 생성 버튼을 비활성화한다.
6. **만들기**를 눌러 세션을 생성한다. 별칭 입력에서 Enter로도 생성할 수 있다. **취소**나 Esc로 창을 닫으며, 창 밖을 눌러도 입력이 사라지지 않는다.

계정 추가·로그인은 **설정 → 에이전트 → Codex/Claude**에서 진행한다. SSH 프로젝트에는 로컬 계정 선택과 로컬 고급 실행 설정이 표시되지 않는다. 세션의 실제 시작·복원 동작은 [세션 수명 주기](session-lifecycle-and-resume.md)를 따른다.

**새 프로젝트**에서도 같은 첫 세션 설정을 사용한다. 왼쪽에서 프로젝트 이름·실행 위치·폴더를 정하고 오른쪽에서 첫 세션 도구를 명시적으로 고른다. 실행 위치를 **원격 호스트 (SSH)**로 바꾸면 SSH 호스트와 원격 폴더가 표시된다. 로컬·SSH를 바꿔도 입력한 로컬 폴더는 유지하며, 다른 실행 위치의 사이드바 폴더 선택은 해제한다.

2026-10-12 개발 소스에서 **문서·HTML 병렬 작업자** 설정과 자동 위임 기능을 제거했다. 설정·세션 속성·새 프로젝트·새 세션에 해당 항목이 표시되지 않으며, 기존 `workerSettings` 저장값은 불러오거나 새 실행에 적용하지 않는다. 일반 모델·effort·Fast, 계정 분산, 사용자 추가 지침은 각 설정 경로를 계속 사용한다. 이미 실행 중인 세션은 이 변경을 포함한 앱에서 다시 시작해야 새 실행 구성이 적용된다.

## 화면 배치

1.8.1.41에서 새 세션 창의 최대 너비는 **720px**, 새 프로젝트 창은 **920px**이다. 새 프로젝트는 프로젝트와 첫 세션을 두 열로 나누고, 새 세션은 별칭·도구와 계정을 가로로 배치한다. 두 창 모두 고급 실행 설정을 필요할 때 펼친다. 계정 관련 안내는 선택창 아래 전체 너비로 표시한다. 1.8.1.36의 1,016px 새 세션 배치 이후 개선이며 적용하려면 1.8.1.41 이상 EXE를 설치한다.

**두 창 모두 헤더와 취소·만들기 버튼은 항상 보인다.** 설정 내용만 내부에서 스크롤한다. 기본 설정은 일반적인 1366×768 데스크톱에서 스크롤 없이 표시되며, 화면 높이가 낮거나 추가 설정을 펼치면 본문만 스크롤한다. 너비 820px 이하에서는 프로젝트의 두 열을 한 열로 전환하고, 더 작은 화면에서는 실행 옵션을 세로로 배치한다.

Tab·Shift+Tab 포커스는 창 안에서 순환한다. Esc는 별칭뿐 아니라 다른 설정에 포커스가 있어도 취소하며, 닫힌 후에는 창을 열었던 컨트롤로 포커스를 되돌린다. 앱의 테마와 언어 설정을 따른다.

## 검증

2026-10-12 작업자 기능 제거 후 관련 **13개 파일 / 188개 테스트**와 TypeScript·Vite
빌드가 통과했다. 기존 작업자 저장값이 있어도 복원·새 세션 생성·실행 명령에 적용되지
않으며, 사용자 추가 지침과 계정·실행 플래그는 보존되는 것을 확인했다. 새 세션·프로젝트
Electron 검사에서 **18개 화면 조합**의 생성 동작·헤더/하단 버튼·가로 넘침을 확인했다.
별도 계정/설정 검사에서 Codex·Claude 기본 계정, 권한·Alt-screen 기억, 세션 속성 저장과
설정 화면 배치를 확인했다. 전용 작업자 UI·CLI 검사는 기능과 함께 제거했다.

`app/`에서 `npm run electron:new-session-smoke`를 실행한다. 별도 Electron 사용자 프로필과 예시 계정 응답을 사용하며, 실제 로그인이나 CLI 세션을 실행하지 않는다.

- 새 세션·새 프로젝트에서 계정·실행 플래그·고급 경로가 생성 payload에 유지되는지 확인한다. 제거된 작업자 설정은 payload에 포함하지 않는다.
- 프로젝트 폴더 선택, 로컬·SSH 전환, 실행 위치별 사이드바 폴더와 첫 세션 입력을 확인한다.
- 도구 전환, SSH·프로젝트 미선택, 분산 비활성 안내를 확인한다.
- 바깥 클릭, Esc·취소, 포커스 순환·복귀와 하단 버튼 노출을 확인한다.
- 두 창을 각각 1366×768, 1920×1080, 1024×768, 390×844, 375×667, 844×375에서 기본·고급 상태와 한국어·영어, Soft·Light·Warm 테마로 확인한다. 실제 CSS 너비와 창 높이는 실행 로그에 기록한다.

승인한 [HTML 초안](mockups/session-create-wide.html)과 [전체 배치 이미지](mockups/session-create-wide.png)는 디자인 참고 자료로 보존한다. 구현은 앱의 실제 계정·기본값·모델 설정 컴포넌트를 사용한다.
