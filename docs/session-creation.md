# 데스크톱 새 세션 만들기

1. 사이드바에서 프로젝트를 선택하고 **새 세션**을 연다.
2. 왼쪽 **세션 설정**에서 별칭과 AI 도구를 고른다. 실행 옵션의 초기값은 설정에 저장된 도구별 기본값을 따른다.
3. 로컬 Codex·Claude 세션이면 로그인 계정을 선택한다. Codex 계정 분산이 등록되어 있으면 **분산 계정**도 표시한다. **자동 배정**은 세션 시작 시 계정을 배정하며, 특정 계정은 다음 시작부터 고정한다. 고정한 계정을 사용할 수 없으면 시작하지 않는다. 분산이 꺼진 경우에는 안내가 표시된다.
4. 필요한 경우 Dangerous 모드와 Codex의 Alt-screen 모드를 바꾼다.
5. Codex 세션은 오른쪽 **문서·HTML 병렬 작업자**에서 문서와 HTML의 도구·모델·추론 강도를 각각 선택한다. **사용 안 함**으로 개별 작업자를 끌 수 있고, **직접 입력…**으로 CLI가 지원하는 모델 ID를 지정할 수 있다.
6. 실행 경로·추가 인수·환경변수가 필요하면 아래 **고급 실행 설정**을 펼친다. 잘못된 고급 설정은 생성 버튼을 비활성화한다.
7. **만들기**를 눌러 세션을 생성한다. 별칭 입력에서 Enter로도 생성할 수 있다. **취소**나 Esc로 창을 닫으며, 창 밖을 눌러도 입력이 사라지지 않는다.

계정 추가·로그인은 **설정 → 에이전트 → Codex/Claude**에서 진행한다. SSH 프로젝트에는 로컬 계정 선택과 로컬 고급 실행 설정이 표시되지 않는다. 세션의 실제 시작·복원 동작은 [세션 수명 주기](session-lifecycle-and-resume.md)를 따른다.

## 화면 배치

1.8.1.36부터 창의 최대 너비는 **1,016px**이다. 왼쪽은 세션·계정·실행 옵션, 오른쪽은 문서·HTML 작업자로 나눈다. 작업자 도구·모델·추론 강도는 한 행에 배치한다. 계정 관련 안내는 선택창 아래 전체 너비로 표시한다.

**헤더와 취소·만들기 버튼은 항상 보인다.** 설정 내용만 내부에서 스크롤한다. 기본 설정은 일반적인 1366×768 데스크톱에서 스크롤 없이 표시되며, 화면 높이가 낮거나 고급 설정을 펼치면 본문만 스크롤한다. 너비 820px 이하에서는 한 열로 전환하고, 더 작은 화면에서는 작업자 도구 선택과 모델·추론 강도 선택을 두 행으로 나눈다.

Tab·Shift+Tab 포커스는 창 안에서 순환한다. Esc는 별칭뿐 아니라 다른 설정에 포커스가 있어도 취소하며, 닫힌 후에는 창을 열었던 컨트롤로 포커스를 되돌린다. 앱의 테마와 언어 설정을 따른다.

## 검증

`app/`에서 `npm run electron:new-session-smoke`를 실행한다. 별도 Electron 사용자 프로필과 예시 계정 응답을 사용하며, 실제 로그인이나 CLI 세션을 실행하지 않는다.

- 계정·작업자 설정·실행 플래그·고급 경로가 생성 payload에 유지되는지 확인한다.
- 도구 전환, 작업자 끄기, 모델별 추론 강도 범위, SSH·프로젝트 미선택, 분산 비활성 안내를 확인한다.
- 바깥 클릭, Esc·취소, 포커스 순환·복귀와 하단 버튼 노출을 확인한다.
- 1366×768, 1920×1080, 1024×768, 390×844, 375×667, 844×375에서 기본·고급 상태와 한국어·영어, Soft·Light·Warm 테마를 확인한다. Windows 배율에 따른 실제 CSS 너비는 실행 로그에 기록한다.

승인한 [HTML 초안](mockups/session-create-wide.html)과 [전체 배치 이미지](mockups/session-create-wide.png)는 디자인 참고 자료로 보존한다. 구현은 앱의 실제 계정·기본값·모델 설정 컴포넌트를 사용한다.
