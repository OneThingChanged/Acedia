# 1.8.2.14 — Remote / Dashboard 공통 작업실

2026-11-13 Standard EXE를 공개했다. 1.8.2.13의 보드·세션 전달 개선도 포함한다. 기존 서명 APK 1.8.1.39를 포함하며 새 APK·Store·Company 배포는 수행하지 않았다.

- 상세 HTML 초안을 바탕으로 대화·문서·사용량 중심의 공통 화면을 적용했다. 도구·설정을 접고 빈 Screen 영역을 숨긴다. 대화로 돌아가면 마지막으로 보던 세션을 사용한다.
- PC는 확인할 일·메모·문서를 바로 열고, 모바일·폴드·태블릿의 터치 모드는 기존 Chat 헤더와 더 보기 메뉴를 유지한다. 세션명과 부모 관계, 실제 작업 폴더를 보존한다.
- 채팅과 문서가 표·코드 블록·목록·인용문 구조를 공유한다. 파일 링크는 각 화면의 기존 권한·경로 계약을 유지하며 표만 가로 스크롤한다. 코드 복사는 코드 원문만 복사한다.
- 문서 원문/미리보기 전환은 이미 읽은 문자열로 동작한다. 원문을 실행하지 않으며, 기존 격리 HTML 뷰어와 ZIP 다운로드를 유지한다.
- 확인할 일 패널은 실제 질문과 미확인 응답만 보여준다. 결과를 열면 기존 읽음 처리를 사용하고, 질문을 여는 것만으로 답변하거나 승인하지 않는다. 사람용 메모의 저장·충돌 처리는 유지한다.
- 계정 한도를 사용 이력보다 먼저 배치하고, 기존 세션 토큰 조회·환산 기준을 유지한다. 라우팅 요청 기록은 시간·세션·계정·처리 상태·토큰 표로 표시한다.
- 새 정적 자산을 두 서버와 PWA v113 캐시에 함께 등록했다. 예시 세션·계정·사용량·문서 데이터는 포함하지 않는다.

검증: 전체 Vitest **249개 파일 / 2,016개 테스트**가 실패·대기 없이 통과했다. TypeScript/Vite 빌드와 실제 렌더러의 DOM 기반 문서 원문 전환·표·코드 이스케이프·검토 패널·터치 도구 재배치도 확인했다. 최초 실행의 Git PATH 누락과 전체 병렬 실행 중 WACK 검증 시간 초과를 구분했으며, Git 경로를 복구하고 작업자 수를 4개로 제한한 최종 전체 실행이 통과했다. GUI 자동화와 실제 사용자 세션으로의 메시지 전송은 수행하지 않았다.

변경 계약과 초안에서 제품으로 가져온 범위는 [Remote 공통 작업실](remote-service.md#shared-workspace-ux-18214)에 정리했다.


## 패키지 검증

- 제품 소스 커밋은 `d888795be52ef6477a68325db2dbe5e4bd3226c7`으로 고정했다. 소스와 ASAR 런타임·렌더러 404개 파일, Pixel Office 자산·라이선스 20개 및 정본 라이선스·제3자 고지의 일치를 확인했다.
- 독립 프로필의 Electron Node 런타임으로 Remote·Dashboard 인증 HTTP, 새 공통 UX 자산·표 안의 파일 링크·검토 상태, 한글 첨부, 부모·자식 조회, 대화 큐, 보드 종료·재열기 어댑터와 native PTY를 검증했다. 화면 조작이나 운영 세션으로의 메시지 전송은 수행하지 않았다.
- 첫 패키징에서 링크로 공유한 의존성의 전이 모듈 누락을 찾아 게시하지 않았다. 의존성을 독립 복사한 후 동일 소스·버전을 다시 빌드하고 패키지 검사에 통과했다. 전달 검사 fixture에는 요청 키별 실제 수락 이후에만 시작 영수증을 반환하도록 현재 계약을 반영했다.
- 실행용 의존성 감사는 취약점 0건이다. 전체 개발 의존성 감사에는 minimatch와 빌더 연쇄의 moderate 6건이 남아 있다. 해당 build-only minimatch가 최종 ASAR에 포함되지 않음을 별도로 검사했다. [상위 보안 권고](https://github.com/advisories/GHSA-g3hv-75wg-m249).
- 로컬·공개 EXE의 NSIS CRC `9262b95f`, 내부 압축 데이터 전체 및 설치 전 검증 모드 시작이 통과했다. Authenticode는 기존 EXE 채널과 같은 `NotSigned`다. 실제 설치와 사용 중인 앱 종료는 실행하지 않았다.
