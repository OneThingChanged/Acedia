# 세션별 사용량

Usage → **세션별 사용량**에서 현재 PC에 수집된 Codex·Claude 대화 기록을 Acedia 세션별로 확인한다. 로컬 Dashboard와 승인된 Remote/PWA에서 같은 집계를 사용한다. `?usage=1&sessions=1`로 직접 열 수 있다.

오늘, 최근 7일, 이번 달, 전체 기록을 선택하고 프로젝트·AI·세션 상태·이름·모델로 필터링한다. 날짜 경계는 앱을 실행하는 PC의 로컬 시간이다. 사용량이 없는 등록 세션과 연결이 확인되지 않은 과거 대화도 구분해 표시한다. 검색 결과의 상위 세션은 트리 맥락만 제공하며 필터 합계에 포함하지 않는다.

## 세션 연결

작업 폴더가 같다는 이유로 기록을 첫 번째 세션에 배정하지 않는다. 현재 대화 ID, 계정별 저장 대화 ID, 휴면·복원 대화 ID 또는 해당 세션의 완료 훅으로 연결을 확인한다. 두 세션이 같은 대화 ID를 주장하면 자동으로 소유자를 결정하지 않는다.

확인된 연결은 이벤트의 `owner_kind`와 세션 ID에 저장한다. 이후 대화를 새로 시작하거나 계정을 바꿔도 이미 연결된 기록은 원래 세션에 남는다. 백그라운드 수집 이후 완료 훅이 도착하면 연결 미확인 기록의 소유자만 보완하고 토큰을 다시 추가하지 않는다. 기존 DB에는 열만 추가하며 기록을 삭제하거나 전체 로그를 다시 읽지 않는다.

기존의 폴더 추정만으로 배정된 기록은 정확한 대화 ID를 찾을 수 있을 때 연결하고, 그렇지 않으면 **연결 미확인 대화**로 따로 보존한다. 등록 세션을 삭제해도 확인된 과거 사용량은 지난 대화로 남는다. 과거 로그 자체가 없거나 지원 형식이 아니면 사용량을 복구할 수 없다. 로컬에 없는 SSH 기록은 수집하지 않는다.

## 토큰과 비용

각 행은 해당 세션의 사용량만 보여준다. 부모·자식 묶기는 [세션 조직도](session-organization.md)의 같은 프로젝트 관계를 사용하며, 상세의 **자식 포함**에서 현재 필터에 포함된 후손을 한 번씩 더한다. 상단 합계는 접기나 상세 선택에 영향을 받지 않는다.

일반 입력, 캐시 읽기·쓰기, 일반 출력, 추론 출력을 별도로 표시한다. 입력·출력의 캐시·추론 부분을 총 토큰에 중복 합산하지 않는다. 모델 변경 시 현재 선택 모델이 아니라 각 기록의 모델로 환산하고 합산 전에는 반올림하지 않는다.

금액은 **API 단가 기준 USD 환산액**이다. [기존 2026-09-13 단가 스냅샷](usage-cost-comparison.md)을 재사용하며 실제 구독 요금이나 공급자의 청구액이 아니다. 지원 모델의 Codex v2 기록만 환산한다. Claude 및 단가·형식 미지원 기록은 토큰을 보존하고 **미산정**으로 표시한다. Fast·긴 문맥 할증, 캐시 쓰기 비용, 도구 비용과 세금은 포함하지 않는다.

환산 범위는 전체 사용 이벤트 중 가격을 계산할 수 있는 이벤트의 비율이다. 일부만 지원되면 환산 가능한 기록의 소계임을 표시한다. 알려진 0달러, 가격 미산정, 사용 기록 없음은 서로 다른 상태다. 상세의 최근 7일 그래프는 선택 기간과 별도로 마지막 일곱 날짜를 표시한다.

## 조회와 내보내기

사용량 응답은 저장된 DB를 바로 집계하고 기존의 제한된 백그라운드 수집을 요청한다. 수집 중에는 1초, 그 외에는 30초 간격으로 갱신하며 탭·페이지가 숨겨지면 중지한다. 조회나 수집이 실패하면 마지막으로 확인한 값을 유지하고 다시 시도할 수 있다. 새로운 CLI 모델 작업을 시작하지 않는다.

목록은 50행씩 표시하지만 합계·상세·CSV는 현재 필터에 맞는 기간 전체 기록을 사용한다. CSV에는 토큰 분류, 모델, 환산액 소수점 여섯 자리, 환산·미산정 건수를 저장한다. 가격 미산정 또는 사용 기록이 없는 값은 빈 칸이며, 사용자 이름을 수식으로 실행하지 않도록 이스케이프한다. 브라우저 API와 CSV에 로컬 로그 경로를 포함하지 않는다.
