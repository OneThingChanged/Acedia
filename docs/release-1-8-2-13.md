# 1.8.2.13 — 보드 검토와 세션 전달 개선

소스 정리: 2026-11-13. 이 기록은 Git 소스 갱신이며 EXE·APK·Store 공개 배포를 뜻하지 않는다.

- 저장된 세션 이름이 실행 중 UUID나 이전 별칭으로 덮어써지지 않도록 했다.
- 보드 프로젝트 자유 배치, 같은 부모 아래 세션 순서, Sleeping·대기/정지 표시 선택을 로컬에 저장한다. 개별 세션의 프로젝트 밖 자유 배치나 부모 변경 기능은 아니다.
- 결과를 열거나 대화로 이동하면 당시 확인한 결과만 읽음 처리한다. 새 결과·질문·오류는 남긴다. 중간 버튼 패닝, 업무순 정렬, 상태 설명과 비활성 표시를 추가했다.
- 세션 메시지 알림은 초기화·작업·질문·기존 입력 중 대기하며, 명확히 입력되지 않은 실패만 제한적으로 재시도한다. 알 수 없는 전송 결과는 자동 재전송하지 않는다. 같은 요청 키와 대상 대화를 고정한다.
- 완료 전달 이력은 별도 영수증으로 보존해 중복 방지 정보를 유지한다. 저장됨·수신 알림·본문 읽음·작업 시작을 구분해 표시한다.
- Remote와 Dashboard의 세션명은 첫 줄 전체 폭을 쓰고 상태·아이콘·부모 정보·작업 버튼은 둘째 줄에 표시한다. 정적 캐시는 v112다.

검증: 전체 Vitest 2,008개 통과 기록과 TypeScript/Vite 빌드 성공을 확인했다. 정리 직전 전달·메시지·Remote 트리 테스트 49개를 재실행해 통과했다. 실제 사용자 세션에 검증 작업을 전송하거나 GUI를 조작하지 않았다.

상세 계약은 [세션 조직](session-organization.md), [작업창 동작](workspace-interactions.md), [Remote](remote-service.md)에 유지한다.

다음 작업은 별도 변경으로 Remote/Dashboard 공통 UX를 상세 초안에 맞춰 실제 데이터와 연결하는 것이다. 초안의 예시 계정·사용량·문서·세션은 제품 데이터에 추가하지 않는다.
