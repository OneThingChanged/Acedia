# 세션·프로젝트 속성과 계정 한도 표시

소스 1.8.0.18부터 프로젝트와 세션 속성은 최대 1120px의 공통 창을 사용한다.
‘넓게’로 창 여백 안까지 확장하고 ‘기본 크기’로 돌아간다. 머리글과 하단 버튼을
고정하며 내용 영역만 스크롤한다. 좁은 창에서는 왼쪽 메뉴가 가로 탭으로 전환된다.
긴 폴더 경로는 줄바꿈으로 전부 표시하고 복사·위치 열기를 제공한다. 원격 경로는
복사만 제공한다. 식별자와 진단 정보는 펼쳐서 확인한다.

## 세션 속성

| 탭 | 내용 |
|---|---|
| 기본 정보 | 프로젝트, 도구, 현재 계정, 실행 위치·상태, 생성 시각, 작업 폴더와 진단 정보 |
| 실행 옵션 | 계정, 권한 확인 생략, Alt-screen, 보조 작업자, CLI 경로·인수·환경변수 |
| 대화 기록 | 현재 대화 ID에 연결된 원본 JSONL 파일의 용량·수정 시각·위치·삭제 |

실행 옵션은 입력 중 앱 상태를 변경하지 않는다. 탭을 바꿔도 초안을 유지하며
**변경 저장**을 눌러 반영한다. 잘못된 입력은 저장을 막는다. 닫기·Escape·배경 클릭으로
저장하지 않은 편집을 버리려면 확인해야 한다. ‘현재 값 다시 불러오기’도 초안을 버리기
전에 확인한다. 다른 창에서 같은 실행 옵션이 바뀌면 덮어쓰지 않고 재확인을 안내한다.

저장된 실행 옵션은 세션을 비활성화한 뒤 다시 열 때 적용된다. 저장 자체로 실행 중인
프로세스를 중단하거나 새로 시작하지 않는다. 계정은 비활성 세션에서 선택하고 저장한다.
저장 직전에도 상태를 확인하며 실제 계정 전환 경계의 실행 중 보호 규칙을 유지한다.
계정 전환 실패는 초안을 보존한다. 계정별 대화 복원 규칙은 기존과 같다.

## 프로젝트 속성

| 탭 | 내용 |
|---|---|
| 개요 | 등록 세션·실행 중 세션·원본 대화 파일 용량, 폴더, 최근 목록과 관리 화면 연결 |
| 현재 세션 | 등록된 세션의 도구·활성 여부와 세션 속성으로 이동 |
| 명령 및 시작 | 전역·프로젝트 저장 명령과 프로젝트 시작 명령 |
| 기록 관리 | 현재 세션에 연결된 기록과 지난 대화의 분리, 이름·ID·경로·도구 검색 |

명령 편집 초안은 탭을 옮겨도 유지하고 닫을 때 확인한다. 명령은 **명령 저장**으로,
시작 명령 선택·자동 실행 여부는 변경 즉시 저장한다. 실제 실행은 기존 새 셸 실행
동작을 사용한다. 입력만으로 기존 AI 세션에 명령을 보내지 않는다.

‘지난 대화’는 이 프로젝트의 현재 등록 세션과 연결되지 않은 카탈로그 기록이다.
용량과 파일 수는 실제 조회 결과를 사용하며 오류·원격 미지원 상태를 0으로 대신하지
않는다. JSONL 원본과 앱 대화 보관함(SQLite)을 구분해 안내한다. 파일 상세를 펼치면
전체 경로와 위치 열기·삭제가 나타난다. 삭제는 확인 후 휴지통으로 이동하며 실행 중인
세션 기록은 화면과 백엔드에서 보호한다. 프로젝트의 원격 저장소는 조회하지 않는다.

## 계정 한도

상태 표시줄의 **계정 한도**에서 현재 표시 계정과 ‘이전·기타 프로필’을 확인한다.
Remote/PWA Usage도 같은 프로필 기준을 사용하며 이전·기타 프로필을 접어서 표시한다.

* 기본 로그인과 등록된 로컬 세션에서 사용 중인 프로필을 기본 화면에 표시한다.
  여기서 사용 중은 세션의 계정 연결을 뜻하며 PTY 실행 여부와는 별개다.
* 세션에서 쓰지 않는 추가 프로필, 등록 목록에서 사라진 프로필의 저장된 한도,
  사용자가 숨긴 프로필은 별도 영역에서 확인한다. ‘이전’이라는 이름만으로 분류하거나
  이름·사용률이 같은 계정을 하나로 합치지 않는다.
* **기본 표시에서 숨기기**와 **기본 화면에 표시**는 명시적 표시 선택이다.
  후자는 현재 세션에서 쓰지 않는 프로필도 기본 화면에 표시하도록 지정한다.
* 표시 선택은 `usage.db`의 `usage_profile_visibility`에 제공자와 계정 ID별로 저장한다.
  자격 증명·원본 대화·토큰 집계·한도 스냅샷은 변경하지 않는다. 앱 재시작 후 유지하며
  다른 앱 창과 Remote/PWA는 다음 조회 때 같은 선택을 읽는다.
* 계정의 전체 한도를 먼저 보여 주고 추가 모델 한도를 펼쳐 확인한다. 각 한도는 자체
  갱신 시각을 표시한다. 갱신 실패 시 기존 스냅샷과 시각을 유지하며 수치를 추정하지 않는다.
  기존 최근 30일 스냅샷 조회 범위는 유지한다.

상태 표시줄 전체 표시·제공자 필터·사용/잔여 비율은 기존 화면 설정이다. 프로필별
표시 선택만 앱과 Remote/PWA에 공유한다. 원격 변경은 기존 인증과 동일 출처 검사를
통과한 JSON 요청만 허용한다.

## 검증

`app/`에서 `npm test`, `npm run build`, `npm run electron:properties-smoke`,
`npm run electron:advanced-launch-smoke`, `npm run electron:workspace-layout-smoke`,
`npm run electron:settings-search-smoke`, `npm run electron:remote-pwa-smoke`를 사용한다.

속성창 검사는 실제 React 컴포넌트를 1202×801, 800×640, 390×844에서 열어 폭·스크롤·
하단 버튼, 초안 유지·저장·충돌, 계정 실패, 기록 검색·삭제 취소·활성 기록 보호와
프로필 표시 변경을 검증한다. 파일·계정·명령은 테스트 대역을 사용한다. 원격 화면은
별도 임시 서버에서 데스크톱·모바일 렌더링과 실제 표시 설정 HTTP 왕복을 확인한다.
SQLite 검사는 표시 선택의 재시작 유지와 원본·스냅샷 보존, 계정별 구분을 확인한다.
실제 사용자 계정 로그인이나 사용자 기록 삭제는 검증 과정에 포함하지 않는다.
