# 세션·프로젝트 속성과 계정 한도 표시

소스 1.8.0.18부터 프로젝트와 세션 속성은 최대 1120px의 공통 창을 사용한다.
‘넓게’로 창 여백 안까지 확장하고 ‘기본 크기’로 돌아간다. 머리글과 하단 버튼을
고정하며 내용 영역만 스크롤한다. 좁은 창에서는 왼쪽 메뉴가 가로 탭으로 전환된다.
긴 폴더 경로는 줄바꿈으로 전부 표시하고 복사·위치 열기를 제공한다. 원격 경로는
복사만 제공한다. 식별자와 진단 정보는 펼쳐서 확인한다.

## 세션 속성

| 탭 | 내용 |
|---|---|
| 기본 정보 | 프로젝트, 도구, 현재 계정, 실행 위치·상태, 생성 시각, 작업 폴더와 진단 정보 |
| 실행 옵션 | 계정, 권한 확인 생략, Alt-screen, 보조 작업자, CLI 경로·인수·환경변수 |
| 대화 기록 | 현재 대화 ID에 연결된 원본 JSONL 파일의 용량·수정 시각·위치·삭제 |

실행 옵션은 입력 중 앱 상태를 변경하지 않는다. 탭을 바꿔도 초안을 유지하며
**변경 저장**을 눌러 반영한다. 잘못된 입력은 저장을 막는다. 닫기·Escape·배경 클릭으로
저장하지 않은 편집을 버리려면 확인해야 한다. ‘현재 값 다시 불러오기’도 초안을 버리기
전에 확인한다. 다른 창에서 같은 실행 옵션이 바뀌면 덮어쓰지 않고 재확인을 안내한다.

저장된 실행 옵션은 세션을 비활성화한 뒤 다시 열 때 적용된다. 저장 자체로 실행 중인
프로세스를 중단하거나 새로 시작하지 않는다. 계정은 비활성 세션에서 선택하고 저장한다.
저장 직전에도 상태를 확인하며 실제 계정 전환 경계의 실행 중 보호 규칙을 유지한다.
계정 전환 실패는 초안을 보존한다. 계정별 대화 복원 규칙은 기존과 같다.

처음 사용하는 Codex·Claude 계정으로 바꾸면 **현재 작업을 새 계정에 인계**가 기본으로
선택된다. 최근 사용자 요청과 일반 응답만 길이를 제한해 로컬에서 인계문으로 만들고,
새 대화가 시작될 때 첫 프롬프트로 전달한다. 도구 출력과 추론 내용은 포함하지 않는다.
대상 계정의 기존 대화를 찾으면 인계문을 보내지 않고 그 대화를 복원한다. 인계 대기 상태는
앱 재시작 후에도 유지되며 새 세션 ID가 확인되면 제거된다. 저장 전에 체크를 해제할 수 있다.

## 프로젝트 속성

| 탭 | 내용 |
|---|---|
| 개요 | 등록 세션·실행 중 세션·원본 대화 파일 용량, 폴더, 최근 목록과 관리 화면 연결 |
| 현재 세션 | 등록된 세션의 도구·활성 여부와 세션 속성으로 이동 |
| 명령 및 시작 | 전역·프로젝트 저장 명령과 프로젝트 시작 명령 |
| 기록 관리 | 현재 세션에 연결된 기록과 지난 대화의 분리, 이름·ID·경로·도구 검색 |

명령 편집 초안은 탭을 옮겨도 유지하고 닫을 때 확인한다. 명령은 **명령 저장**으로,
시작 명령 선택·자동 실행 여부는 변경 즉시 저장한다. 실제 실행은 기존 새 셸 실행
동작을 사용한다. 입력만으로 기존 AI 세션에 명령을 보내지 않는다.

‘지난 대화’는 이 프로젝트의 현재 등록 세션과 연결되지 않은 카탈로그 기록이다.
용량과 파일 수는 실제 조회 결과를 사용하며 오류·원격 미지원 상태를 0으로 대신하지
않는다. JSONL 원본과 앱 대화 보관함(SQLite)을 구분해 안내한다. 파일 상세를 펼치면
전체 경로와 위치 열기·삭제가 나타난다. 삭제는 확인 후 휴지통으로 이동하며 실행 중인
세션 기록은 화면과 백엔드에서 보호한다. 프로젝트의 원격 저장소는 조회하지 않는다.

## 계정 한도

하단바의 계정 항목을 누르면 **에이전트 사용량**에서 모든 현재 계정과
‘이전·기타 프로필’을 확인한다. 계정별로 **하단바에 표시**를 선택하며 한 번에 한 계정만
하단바에 표시한다. 이 선택은 세션 로그인이나 새 세션 기본 계정을 변경하지 않는다.
Remote/PWA Usage도 같은 프로필 기준을 사용하며 이전·기타 프로필을 접어서 표시한다.

* 소스 1.8.0.19부터 등록된 Codex·Claude 추가 계정은 세션 연결·실행 여부와 관계없이
  각각 표시한다. 계정 목록을 한도 스냅샷과 별도로 전달하므로 수집 전 계정도 빠지지 않는다.
  기본 로그인도 한도 조회 결과가 있으면 표시하며, 미로그인 상태를 별도로 안내한다.
* 한도가 아직 수집되지 않은 계정은 **한도 확인 전**으로 표시한다. 0%나 잔여량을 만들지
  않는다. 같은 창에서 계정을 추가하면 목록을 다시 읽고, 다른 창은 다음 조회 때 반영한다.
* 하단바는 선택한 계정의 이름·주요 한도만 한 항목에 표시한다. 기본 로그인은 **기본**으로
  구분하고 높이 28px을 유지한다. 모든 계정의 상세 한도와 요금제는 사용량 창에 모은다.
* 하단바 선택은 계정 ID로 저장하므로 이름을 바꾸거나 목록 순서가 바뀌어도 유지한다.
  앱 재시작과 작업창 사이에도 유지하며 저장 실패 시 이전 선택과 오류 안내를 표시한다.
  표시 중인 계정이 삭제·숨김 처리되면 같은 도구의 기본 로그인, 다른 표시 가능한 기본
  로그인, 첫 표시 가능 계정 순서로 대체한다. 선택 가능한 계정이 없어도 사용량 창을 열 수 있다.
* 상태 표시줄의 도구 필터를 끄면 그 도구의 계정은 하단바 선택에서 제외한다. 사용량 창에서는
  계속 확인할 수 있다. 한도를 수집하지 않은 등록 계정도 하단바에 선택할 수 있다.
* 과거 이전용으로 저장된 절대 폴더 경로와 고정 접미사 형식의 프로필, 등록이 해제된
  계정과 사용자가 숨긴 프로필은 별도 영역에 표시한다. 이전용 이름은 되돌릴 수 있는
  기본 표시 판단에만 사용한다. 임의의 ‘이전’ 단어나 이름·사용률의 일치로 계정을 합치거나
  같은 자격 증명이라고 판단하지 않는다.
* **기본 표시에서 숨기기**와 **기본 화면에 표시**는 명시적 표시 선택이다.
  사용자의 명시적 선택은 이전용 이름에 따른 기본 분류보다 우선하며 수집 전 계정에도 적용된다.
* 표시 선택은 `usage.db`의 `usage_profile_visibility`에 제공자와 계정 ID별로 저장한다.
  자격 증명·원본 대화·토큰 집계·한도 스냅샷은 변경하지 않는다. 앱 재시작 후 유지하며
  다른 앱 창과 Remote/PWA는 다음 조회 때 같은 선택을 읽는다.
* 계정의 전체 한도를 먼저 보여 주고 추가 모델 한도를 펼쳐 확인한다. 각 한도는 자체
  갱신 시각을 표시한다. 갱신 실패 시 기존 스냅샷과 시각을 유지하며 수치를 추정하지 않는다.
  기존 최근 30일 스냅샷 조회 범위는 유지한다.

하단바의 **새로고침**과 사용량 창의 **모든 계정 새로고침**은 등록된 Codex·Claude
계정을 각각 조회한다. 실행 중인 세션이 없는 계정과 직접 숨긴 계정도 조회하며,
등록 해제된 계정은 저장된 한도만 유지한다. Codex는 계정별 로그인 환경에서
`app-server`의 `account/rateLimits/read`를 호출한다. 대화나 모델 요청을 시작하지 않으며,
로그인 계정·기본 계정·실행 중인 세션을 전환하지 않는다. Claude는 계정별 OAuth
사용량 조회를 사용한다. 표시하는 값은 제공자가 반환한 사용률·리셋 시각이며,
정확한 잔여 토큰 수를 계산하지 않는다.

계정 카드에는 조회 중·조회 완료·로그인 필요·시간 초과·조회 실패·한도 미제공 상태를
표시한다. 실패한 계정은 기존 수치와 갱신 시각을 유지하고 이전 조회 값임을 안내한다.
제공자당 최대 두 계정을 동시에 조회하고, 일부 실패가 나머지 조회를 막지 않는다.
중복 새로고침은 합치며, 조회 중 포커스 이동이나 캐시 읽기가 완료 응답을 덮어쓰지 않는다.
Codex 보조 프로세스는 조회 또는 제한 시간 종료 시 정리한다. 자격 증명과 원본 오류
내용은 화면에 전달하지 않는다.

상태 표시줄 전체 표시·제공자 필터·사용/잔여 비율·하단바 계정 선택은 앱 화면 설정이며
`multiagent.statusBar.v1`에 저장한다. 프로필별
표시 선택만 앱과 Remote/PWA에 공유한다. 원격 변경은 기존 인증과 동일 출처 검사를
통과한 JSON 요청만 허용한다.

## 검증

`app/`에서 `npm test`, `npm run build`, `npm run electron:properties-smoke`,
`npm run electron:advanced-launch-smoke`, `npm run electron:workspace-layout-smoke`,
`npm run electron:settings-search-smoke`, `npm run electron:remote-pwa-smoke`를 사용한다.

속성창 검사는 실제 React 컴포넌트를 1202×801, 800×640, 390×844에서 열어 폭·스크롤·
하단 버튼, 초안 유지·저장·충돌, 계정 실패, 기록 검색·삭제 취소·활성 기록 보호와
프로필 표시 변경을 검증한다. 추가로 Codex·Claude 여섯 계정, 수집 전 두 계정,
하단바 단일 선택·저장 실패·창 재열기·다른 창의 선택 변경·이름 변경·삭제 후 기본 계정 대체,
도구 필터와 28px 높이를 검사한다. 파일·계정·명령은 테스트 대역을 사용한다. 원격 화면은
별도 임시 서버에서 데스크톱·모바일 렌더링과 실제 표시 설정 HTTP 왕복을 확인한다.
SQLite 검사는 표시 선택의 재시작 유지와 원본·스냅샷 보존, 계정별 구분, 수집 전 계정,
이전용 이름의 기본 분류·명시적 복원과 Codex 계정별 조회 기회 보장을 확인한다.
실제 사용자 계정 로그인이나 사용자 기록 삭제는 검증 과정에 포함하지 않는다.

계정 새로고침 변경 검증에서는 656개 테스트와 빌드, 세 가지 창 크기의 실제 Electron
UI 검사를 통과했다. 추가 검사는 미사용·숨긴 계정 조회, 중복 요청 합치기, 부분 실패 시
캐시 보존, 재시도 복구, 보조 프로세스 종료와 화면 오류 표시를 포함한다. 별도 읽기 전용
검증으로 현재 등록된 Codex 기본 로그인과 두 추가 계정의 실제 한도 응답을 확인했다.
Claude 실제 계정 서버 조회는 테스트 대역으로 검증했으며 실제 인증을 수행하지 않았다.
