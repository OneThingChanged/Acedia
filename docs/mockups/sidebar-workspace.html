ACEDIA / SIDEBAR DESIGN 01

시작은 빠르게, 탐색은 단순하게.

참고 화면의 익숙한 탐색 방식에 Acedia의 프로젝트·여러 에이전트·분할 화면을 더한 방향입니다.

01

자주 쓰는 동작을 위에 고정

새 대화 → 검색 → 모든 대화 순서로 접근합니다. 아래 목록을 스크롤해도 시작 버튼과 검색은 같은 자리에 있습니다. Ctrl K는 검색, Ctrl N은 새 대화입니다.

02

프로젝트는 대화의 범위, 분할 화면은 별도 바로가기

프로젝트를 누르면 해당 프로젝트의 대화로 좁혀집니다. 깊은 트리를 매번 펼치지 않고 최근 대화를 바로 선택합니다. 기존 Screen은 ‘분할 화면’으로 설명하고, 이름으로 구분합니다. 프로젝트 관계·폴더·세션 계층의 상세 관리는 보드에서 이어갑니다.

03

제목이 먼저, 상태는 필요한 만큼

대화 제목 아래 프로젝트와 제공자를 작게 표시합니다. 고정 대화·오늘·어제·이번 주로 묶고, 전체·활성·휴면 필터를 유지합니다. 질문을 기다리는 항목에는 글자도 표시합니다. 전체 경로와 상태 설명은 항목에 마우스를 올리면 볼 수 있습니다.

04

관리 기능은 항목 메뉴와 하단으로

대화의 ··· 또는 우클릭에서 고정·이름 변경·보관을 제공합니다. 분할 화면의 해제도 같은 위치에 둡니다. 계정·설정·분산 상태는 하단에 고정하고, 사이드바를 접으면 최소 아이콘만 남깁니다.

이 파일은 독립 HTML 초안입니다. 프로젝트·대화·계정·요청 수는 예시이며, 입력은 현재 열린 초안에서만 반영됩니다. 실제 파일·세션·계정 설정을 변경하거나 AI 요청을 전송하지 않습니다.
