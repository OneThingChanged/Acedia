# Acedia 1.8.1.0

## 사용자 변경 사항

* Codex와 Claude 추가 계정의 표시 이름을 바꾸고 등록을 제거할 수 있다.
* 계정을 제거하면 그 계정을 사용하던 로컬 세션과 새 세션 기본값을 기존 로그인으로
  안전하게 되돌린다. 인증·설정·대화 파일은 보존한다.
* 모든 계정 사용량은 하나의 에이전트 사용량 창에서 확인하고, 하단바에는 선택한 계정
  하나만 표시한다.
* 대화가 없는 다른 계정으로 세션을 바꾸면 최근 사용자 요청과 일반 응답을 길이 제한된
  첫 프롬프트로 인계할 수 있다. 기존 대상 대화가 있으면 그대로 복원한다.
* 서로 다른 분할 패널에서 선택한 브라우저를 동시에 표시하고 조작할 수 있다.

## 버전과 산출물

일반 앱, GitHub 태그, 설치 파일과 Android 소스 versionName은 `1.8.1.0`이다.
npm 호환 버전은 `1.8.1`이다. GitHub용 데스크톱 빌드는 서명·패키지·아키텍처를
확인한 기존 모바일 `1.8.0.1` APK를 재사용하며 새 APK를 만들지 않는다.

Store에는 이미 `1.8.2.0`이 게시되어 있으므로 같은 소스 기능을 담는 Store 패키지는
Microsoft 버전 증가 규칙에 따라 `1.8.3.0`을 사용한다. EXE와 Store의 설치 ID와
업데이트 경로는 분리되고 공통 사용자 프로필을 공유한다.

로컬 GitHub 채널 산출물:

## 검증

* 데스크톱 Vitest: 106개 파일, 620개 테스트 통과
* 모바일 Node 테스트: 24개 통과, TypeScript 타입 검사 통과
* TypeScript/Vite 프로덕션 빌드: 607개 모듈 변환 완료
* 계정 등록·이름 변경·삭제, 속성창 3개 크기, 상태 표시줄 숨김과 재시작,
  고급 실행·인계 프롬프트 네이티브/배치 PTY 전달 검사 통과
* 브라우저 프로필 격리·재시작, 숨김 브라우저 탐색·입력·캡처, 설정 검색 105개,
  브리지 검사 통과
* packaged runtime, dashboard, 종료·트레이·보안 lifecycle 검사 통과

큰 JavaScript chunk 경고와 모바일 테스트의 package type 경고는 기존 비차단 경고다.
packaged PTY 검사 중 보조 프로세스의 `AttachConsole failed` 로그가 발생하지만 최종
브리지·대시보드·lifecycle 판정은 모두 통과했다.
