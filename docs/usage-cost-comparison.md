# API 단가 기준 환산액

전체 현황과 계정·직원 상세, 일·주·월 분석 및 요청 기록에서 USD 환산액을 제공합니다. 이는 **표준·짧은 문맥 단가를 적용한 비교 지표**이며 실제 청구액이나 구독 주간 한도 소진율이 아닙니다. 공급자가 보고한 잔여 한도는 별도로 유지합니다.

- 계산: `(일반 입력 × 입력 단가 + 캐시 입력 × 캐시 읽기 단가 + (출력 + 추론) × 출력 단가) / 1,000,000`.
- 표시: 모든 달러 값은 소수점 두 자리로 반올림합니다. 합산은 원래 정밀도로 수행하며 아주 작은 요청은 `$0.00`으로 보일 수 있습니다.
- 단가: [OpenAI 공식 API 가격표](https://developers.openai.com/api/docs/pricing)의 2026-09-13 확인 값. 구현 스냅샷은 `app/electron/usage-collector/pricing.mjs`이며 Astra, Sol, Terra, Luna, GPT-5.5, GPT-5.4, GPT-5.3-Codex를 지원합니다. 모델명은 정확히 일치해야 합니다.
- Fast·긴 문맥 할증, 캐시 쓰기, 도구 비용, 세금 및 환율은 반영하지 않습니다. Effort에 임의 배수를 적용하지 않으며 실제 수집된 추론 토큰을 출력 단가로 계산합니다.
- 미지원 모델이나 입력·캐시 읽기·출력·추론 세부 수치가 누락된 요청은 0원으로 취급하지 않고 제외 건수를 표시합니다. 일부만 환산되면 표시 금액도 해당 요청의 소계입니다.
- 기간 합계는 최신 500건 제한과 무관하게 조회 기간 전체의 권한 내 기록을 계산합니다. 직원 조회는 본인 기록만 포함합니다. 기존 로그·DB를 다시 수집하거나 수정할 필요 없이 같은 스냅샷 단가로 재계산합니다. 과거 실제 청구 단가의 재현은 지원하지 않습니다.


## Remote 대시보드 단위 전환

Acedia Remote 사용량 화면의 `토큰 / USD` 버튼으로 주·월·년 그래프, 빠른 기간 선택, 기간 합계, 이전 기간 대비, 평균, 최대 사용 구간의 표시 단위를 전환합니다. USD는 소수점 두 자리로 표시하고 합산 전에는 반올림하지 않습니다. 하단 토큰 상세와 공급자 잔여 한도는 각자의 원래 단위를 유지합니다.

Remote는 로컬 `usage_events`의 모델별 세부 토큰을 중앙 서버와 같은 단가 모듈로 환산합니다. Codex v2 형식 외 기록과 미지원 모델은 제외하며 선택 기간의 환산·제외 건수를 표시합니다. 기존 로컬 인덱스에서 누락 여부를 구분할 수 없는 세부 수치는 저장된 정규화 값에 따르므로 실제 청구액 복원용으로 사용하지 않습니다. Electron 서비스 변경은 변경된 소스로 실행하는 앱을 재시작한 뒤 적용됩니다. 설치된 구버전은 새 빌드 설치가 필요하며 브라우저 새로고침만으로 백엔드 계산이 추가되지 않습니다.
## 두 화면의 집계 차이

| 구분 | 중앙 수집 서버 | Acedia Remote |
| --- | --- | --- |
| 데이터 | 전송받은 직원·계정별 이벤트 | 현재 PC의 로컬 사용량 인덱스 |
| 기간 | 일·주·월, 한국 시간 | 주·월·년, 호스트 로컬 시간 |
| 표시 | 환산액 카드·표·개별 요청 열 | 토큰/USD 전환, 토큰 상세는 유지 |
| 미확인 | 필수 토큰 세부 수치 또는 모델 단가가 없으면 제외 | Codex v2 외 형식·미지원 모델 제외, 누락 여부가 사라진 필드는 저장 값 사용 |

두 화면은 같은 단가 모듈을 사용하지만 수집 범위와 시간대가 다르면 합계도 다릅니다. 환산 가능한 기록만 더한 값이므로 제외 건수가 있는 기간의 합계·증감률은 부분 집계입니다. 주간 한도를 달러 예산으로 변환하거나 직원의 실제 한도 소진율을 역산하지 않습니다.

## 검증과 적용 상태 · 2026-09-13

- 커밋 전 전체 테스트 704개(119개 파일)와 OKF 문서 검증을 통과했습니다. 제품 버전은 `1.8.1.9`이며 공개 배포 전 소스 상태입니다.

- 중앙 수집기 관련 테스트 36개 및 Electron 화면 검증 통과. 최신 500건을 넘는 기간 집계, 직원 범위, 미지원 모델, 입력/캐시/추론 계산을 확인했습니다.
- Remote 관련 테스트 31개 통과. 월·주·년 및 빠른 기간 선택의 금액 보존과 신규 기록 이후 캐시 갱신을 확인했습니다. 위 36개와 중복 테스트가 있으므로 숫자를 전체 테스트 수로 합산하지 않습니다.
- Remote Electron 화면 검증에서 1920·1280·390px의 단위 전환, USD 두 자리와 그래프, 토큰 모드 복귀 및 기존 언어·레이아웃 동작을 확인했습니다.
- 독립 서버 패키지 생성·모듈 로딩과 로컬 실행 서버의 환산 필드 응답을 확인했습니다. 중앙 서버 로컬 런타임에는 반영했습니다.
- Remote는 소스와 격리 화면 테스트에 반영한 상태입니다. 이번 변경의 제품 빌드·공개 배포 및 설치된 앱 업데이트는 수행하지 않았습니다.

운영 절차는 [사용량 서버 운영 가이드](usage-server-operations.md), 로컬 인덱스는 [Usage accounting](usage-accounting.md), 전송 범위는 [Central usage collector](central-usage-collector.md)를 참고합니다.


## 중앙 서버 기간별 그래프 · 2026-09-13

전체 현황과 상세 화면에 일별·주별·월별, USD·토큰 전환을 제공합니다. 계정 상세는 사용자별 색상, 직원 상세는 계정별 색상으로 쌓아 표시합니다. 막대를 선택하면 해당 구간의 사용자/계정별 토큰·환산액·환산 제외 건수가 표시됩니다. 그래프와 표는 페이지당 12개 구간이며 합계·구간 평균·최대 구간은 선택 기간 전체 기준입니다. 주 시작은 월요일, 시간대는 한국 시간이며 경계 구간은 조회 기간에 포함된 기록만 합산합니다.

계정 상세의 사용자 구분, 단위 전환, 막대 선택 및 기존 기간·페이지 동작을 Electron 화면 테스트로 확인했습니다. 로컬 중앙 서버 런타임의 HTML·JS에 반영했고 HTTP로 변경된 화면 자산의 응답을 확인했습니다. 제품 빌드 배포와는 별개입니다.


## AI·모델·Effort 사용 구성

직원·계정 상세에 AI 종류·모델·Effort 조합별 도넛과 막대그래프를 표시합니다. USD 환산액·토큰·요청 수를 선택하며 분모는 선택 기간과 계정 구분 필터를 적용한 해당 지표 합계입니다. 구독 한도 소진율이 아닙니다. 모델과 Effort 미확인은 별도 그룹으로 유지하고 USD 환산 불가 요청은 금액 분모에서 제외하며 건수를 표시합니다. 메인·서브에이전트 요청을 포함하고 합계는 최신 500건 제한과 무관합니다.

서버 응답은 직원별·계정별 조합 집계를 보존하여 화면 필터를 지원하고, 직원 인증은 본인 기록만 조회합니다. 항목을 선택하면 요청 수·토큰·환산액·제외 건수를 봅니다. 관련 테스트 36개와 Electron 화면 조작 검증을 통과했고 로컬 서버 반영 후 전체 토큰 합계와 조합 합계의 일치를 확인했습니다.


### 기간 선택에 따른 상세 연동

직원별 사용량과 AI·모델·Effort 구성은 기간별 사용량 블록 안에 표시합니다. 그래프에서 선택한 일·주·월 구간의 토큰·USD·환산 제외와 모델 구성을 함께 갱신합니다. 계정 상세에서는 사용자 이름을 눌러 직원 상세로 이동할 수 있습니다. 모델 집계는 한국 시간 일자별 차원을 보존하여 다른 기간의 기록이 섞이지 않게 필터링하며 빈 구간은 사용 기록 없음으로 표시합니다. 상단 모델 구성과 직원 표의 중복 블록은 제거했습니다.


## 화면 정보 순서와 보조 정보

기간 합계·구간 평균·최대 구간 다음에 페이지 이동과 그래프를 배치합니다. 선택 구간 제목 아래의 사용자/계정별 상세와 모델 구성은 그 구간에만 대응합니다. 전체 조회 기간의 계정 사용률·환산 설명, 스킬 목록과 기간별 수치 표는 펼침 영역으로 유지해 중복과 스크롤을 줄였습니다. 작은 화면은 표 가로 스크롤과 줄바꿈을 지원하며 기간 전환 버튼은 최소 40px 높이입니다.

[날짜별 그래프 초안](mockups/usage-daily-cost.html)과 [모델 구성 초안](mockups/usage-model-effort.html)은 예시 데이터로 동작하는 설계 자료입니다. 실제 수집 화면은 서버의 데이터를 사용합니다.
