# 개별 설정 검색과 적용 범위

Acedia 1.8.0.9부터 설정 왼쪽 검색창에 옵션 이름을 입력하면 개별 항목과 위치, 적용 범위를 표시한다.
일치하는 카테고리도 왼쪽에 남는다. 결과를 선택하면 카테고리와 도구 탭을 열고,
필요한 접힌 영역을 펼친 뒤 해당 항목으로 스크롤하고 키보드 초점과 강조를 옮긴다.
상단의 **검색 결과로 돌아가기**로 같은 검색 결과를 다시 볼 수 있다.

* **환경변수** 또는 **환경 변수**: 도구별 고급 실행 설정을 표시한다.
* **Claude environment**: Claude의 환경변수 항목으로 범위를 좁힌다.
* **커서**: 커서 모양과 깜빡임을 찾는다.
* **기본 계정**, **대시보드 포트**, **SSH 인증**: 각 설정의 편집 위치로 이동한다.
* **브라우저 프로필**, **저장 명령**, **절전 방지**, **한도 비율 표시**, **유휴 시간**: 확장된 설정 항목으로 이동한다.
* **윈도우 부팅**, **Windows 로그인**, **Remote 자동**, **외부 터널 자동**: 앱·Remote 시작 설정으로 이동한다.

한국어·영어 이름과 별칭, 현재 화면에 표시되는 번역 이름을 검색한다.
여러 단어는 모두 일치해야 하며, 정확한 옵션 이름을 먼저 표시한다.
빈 검색어는 현재 설정 화면을 표시하고, 결과가 없으면 검색어를 바꾸도록 안내한다.

## 키보드와 적용 범위

검색창에서 아래 화살표를 누르면 결과 목록으로 이동한다. 목록의 위·아래 화살표,
Home·End로 이동하며 Enter로 선택한다. 검색창에서 Enter를 누르면 첫 결과를 연다.
검색창의 Esc는 검색어를 먼저 지우고, 다시 누르면 앱으로 돌아간다.
한글 등 입력기 조합 중 Enter와 Esc는 검색 선택이나 설정 닫기로 처리하지 않는다.

| 표시 | 의미 |
|---|---|
| 즉시 · 이 앱 | 앱의 표시와 동작에 반영한다. |
| 즉시 · 로컬/SSH | 이 앱이 표시하는 현재·새 터미널에 적용하며 원격 설정 파일은 바꾸지 않는다. |
| 새 로컬 세션 | 생성 시 복사한다. 기존 세션과 SSH에는 적용하지 않는다. |
| 새 세션 기본값 | 새 세션을 만들 때 처음 선택되는 값이다. 기존 세션은 유지한다. |
| 로컬 · 계정별 | 등록한 계정을 로컬 세션에서 선택한다. |
| 다음 CLI 실행 | 저장된 CLI 설정을 다음 로컬 실행부터 사용한다. |
| 저장 후 · 서버/앱 시작 | 저장한 값을 다음 서버 시작 또는 앱 실행부터 사용한다. |
| 즉시 등록 · 다음 Windows 로그인 | 시작 프로그램 체크를 Windows에 즉시 반영하며 다음 로그인부터 적용한다. |
| 저장 버튼으로 적용 | 해당 화면에서 명시적으로 저장한다. |
| 프로젝트 선택 시 | 자동 실행을 켠 프로젝트를 클릭할 때 앱 실행당 한 번 실행한다. 화면 복원만으로 실행하지 않는다. |
| SSH 프로젝트 | 저장한 호스트를 원격 프로젝트에서 선택한다. |
| 직접 실행 | 이동한 항목의 버튼을 사용자가 눌러 실행한다. |

배지와 검색 후 상단 설명은 같은 적용 범위 정보를 사용한다.
검색이나 이동 자체가 계정 로그인, 값 변경·저장, 서버 시작, 진단 수집,
프로세스 재시작을 실행하지 않는다. 기존 설정을 불러오는 읽기 요청은 발생할 수 있다.

## Windows 로그인 자동 실행 (2026-11-02, 소스 구현)

**설정 → 일반 → 앱 시작 → Windows 로그인 시 Acedia 자동 실행**에서 현재 Windows
사용자의 시작 프로그램을 켜거나 끈다. 기본은 등록하지 않음이며 실제 Windows 등록 상태를
조회한다. 체크는 별도 Save 없이 적용한다. Windows 설정·작업 관리자에서 비활성화한
상태도 표시하고, 앱을 켰다는 이유로 다시 활성화하지 않는다. 로그인한 뒤 일반 앱 실행과
같은 창으로 열며 Remote 자동 시작 여부는 별도로 선택한다.

Windows EXE 설치본에서 지원한다. 개발·격리 검증 프로필은 등록하지 않고 Store 설치본의
StartupTask 연동은 아직 지원하지 않는다. 명령에는 실행 경로·레지스트리 이름을 받지 않고
현재 설치본과 채널별 ID를 사용한다. 업데이트 시 등록을 유지하고 제거할 때만 해당 채널의
Run 항목을 정리한다. OS API는 [현재 Electron 버전의 공식 문서](https://github.com/electron/electron/blob/v43.8.3/docs/api/app.md#appsetloginitemsettingssettings)를 따른다.

Remote 설정은 [Remote 자동 시작](remote-service.md)을 따른다. 이 변경은 소스에 반영했으며
공개 배포 전이며 다음 배포 목표는 **1.8.2.00**이다. 사용자 PC의 실제 시작 프로그램이나 실행 중 Remote는 테스트로 변경하지 않는다.

검증은 전체 **215개 파일·1,722개 검사**, 취소 처리 보완 후 관련 **4개 파일·74개 검사**,
TypeScript·Vite production build를 통과했다. 숨김 Electron 설정 화면에서 124개 검색 대상과
ON/OFF·Windows 비활성 상태·미지원 빌드·저장 실패 표시, Remote의 Save 전후를 확인했다.
800/1202/1920px 배치와 기존 계정·모델·대시보드·알림 설정 회귀도 통과했다.
`output/app-startup/tests-full.log`, `tests-final-targeted.log`, `build-final.log`,
`settings-electron-verified.log`, `settings-windows-final.png`, `settings-remote-final.png`에 기록한다.
Windows 어댑터는 모의 API로 검증했으며 실제 OS 자동 실행 등록·재부팅·로그인은 실행하지 않았다.
사용자 계정명·이메일·환경변수 값·토큰·호스트 주소 등은 검색 색인에 포함하지 않는다.

## 구성과 경계

설정 카탈로그는 항목 ID, 카테고리, 도구 탭, 이름, 별칭과 적용 범위를 관리한다.
화면의 이동 대상과 배지는 이 ID를 사용한다. 단축키 항목은 실제 명령 목록에서 생성한다.
1.8.0.15의 기본 구성에서 105개 항목을 제공하며, Company의 리모트 설정과 사용할 수 없는 작업자
옵션은 결과에서 제외한다. 비활성화한 도구의 사용 토글은 계속 검색할 수 있다.

현재 선택에 따라 나타나는 사용자 지정 알림음·TTS·SSH 인증 하위 필드는 관련 설정
그룹으로 안내한다. 검색 때문에 알림 방식이나 원격 운영체제·인증 방식을 바꾸지 않는다.
창 크기나 동적 목록 갱신 후에도 결과의 초점을 임의로 로그인 카드로 이동하지 않는다.
설정에서 돌아가면 가려졌던 기존 작업 화면을 그대로 사용한다.

## 검증

단위 테스트는 이름·별칭·띄어쓰기·도구 필터·표시 언어 검색, 채널·작업자 필터,
항목 ID의 유일성과 단축키 목록·적용 범위 연결을 검사한다.
숨김 Electron은 기본 구성의 모든 이동 대상, 접힌 영역과 반복 이동, 키보드·입력기,
검색값과 설정값의 분리, 읽기 이외 IPC 미호출, 로그인 상태 갱신 중 초점 보존,
800×640, 1202×801, 1920×1080 화면 배치를 확인한다.
1.8.0.15의 기본 구성에 포함된 105개 이동 대상은 좁은 화면에서도 가로 넘침 없이 접근하는지 검사한다.
1.8.0.9에서 검증한 81개 대상에 브라우저·명령·알림 조건·상태 표시줄·유휴 세션 항목을 더한 수다.

검증 명령은 `app/`에서 `npm test`, `npm run build`,
`npm run electron:settings-search-smoke`이다. 설치본 배포와 모바일 UI는 별도다.
