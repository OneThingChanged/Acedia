# Acedia Usage Server

직원별 공용·개인 AI 계정의 토큰 메타데이터를 수집하는 독립 서버입니다. Acedia 설치 없이 Node.js 22.13 이상에서 실행합니다.

저장소 루트에서 `node app/scripts/package-usage-server.mjs <새 출력 폴더>`로 배포 폴더를 생성합니다. 그 폴더를 서버에 복사한 뒤 `node start.mjs --port 3007 --home <데이터 폴더>`로 실행합니다. 별도의 npm 의존성 설치는 필요하지 않습니다. 기본 접속 주소는 `http://127.0.0.1:3007`입니다. 이 PC에서 3004~3006은 기존 서비스가 사용하므로 3007을 할당합니다.

관리 키는 최초 실행 시 생성해 데이터 폴더의 `admin.protected`에 저장합니다. Windows에서는 현재 Windows 사용자의 DPAPI로 보호합니다. 다른 OS에서는 사용자 전용 파일 권한으로 보관합니다. 관리 키를 지정하려면 `ACEDIA_USAGE_ADMIN_TOKEN` 환경 변수에 24자 이상의 무작위 값을 설정합니다. 키를 명령행 인수나 URL에 넣지 마세요. 운영 시 데이터 폴더 접근 권한을 관리자와 서비스 계정으로 제한하세요.

Windows에서 `node admin.mjs --copy --home <데이터 폴더>`를 실행하면 관리 키를 클립보드에 복사합니다. 웹 로그인에 붙여넣고 클립보드를 비우세요. `--stdout`은 명시적으로 키를 터미널에 출력하는 옵션이므로 공유 로그가 없는 로컬 관리 환경에서만 사용합니다. 환경 변수로 키를 덮어쓴 서버는 관리 명령에도 같은 환경 변수를 제공해야 합니다.

기본 수신 주소는 루프백입니다. 원격 운영은 HTTPS 역방향 프록시 뒤에 배치하고 필요한 경우 `--host`를 지정합니다. 수집기는 원격 평문 HTTP를 거부합니다. 직원과 공용/개인 계정을 등록한 뒤 일회용 등록 코드로 각 PC를 연결합니다. 직원 식별자는 서버가 부여하며 계정과 별도로 집계합니다.

일반 ChatGPT·Claude 채팅 토큰의 자동 계측은 지원하지 않습니다. 플러그인의 사용량 조회 도구와 CLI 로그 수집은 별개 기능입니다. 계정 연결은 관리자가 지정한 폴더 매핑이며 공급자의 인증 정보를 검증하는 감사 시스템은 아닙니다.

화면은 전체 현황·계정별 분석·직원별 분석·수집 상태·등록 관리로 구성됩니다. 계정 이메일·식별자와 관측된 잔여 한도·리셋 시각을 토큰 합계와 구분해 표시합니다. 새로고침은 실행 중인 수집기에 계정 조회를 요청하며, 오프라인·실패·만료된 값은 대기 또는 이전 관측값으로 표시합니다. 수집 상태와 상세 기록에는 Windows 계정명·PC 이름·로컬 IPv4 주소를 함께 표시합니다. 과거 기록에 없던 정보는 소급해서 채우지 않습니다.

개발 PC의 로컬 접속 키는 사용자 요청으로 `admin`입니다. 이 값은 루프백 수신 주소에서만 허용합니다. 배포 ZIP에는 키나 데이터가 없으며 다른 PC에서 최초 실행하면 무작위 관리 키를 생성합니다.

등록 관리에서 실제 로그인 이메일과 공용·개인 구분을 등록합니다. 이미 보고된 로그인은 선택해서 이메일·식별자를 채울 수 있고, 기존 계정은 목록의 수정 버튼으로 연결합니다. 서버는 식별자가 등록되어 있으면 그것을 우선하고, 없으면 이메일을 대조해 신규 사용량·한도를 해당 계정으로 합산합니다. 개인 계정은 지정된 소유자의 기기만 사용할 수 있습니다. 이전 기록은 이동하지 않으며, 로그인 미등록 계정은 기본 개인으로 집계합니다. 로그인 정보와 공용 구분을 서버에 등록한 계정만 공용으로 집계합니다.

오른쪽 아래 테마 메뉴에서 시스템·라이트·다크를 선택합니다. 선택은 브라우저에 저장되며 로그인 화면과 상세 창에도 적용됩니다.

직원별 분석의 사용률은 해당 직원이 그 계정에서 사용한 토큰을 모든 직원의 같은 계정 사용 토큰으로 나눈 값입니다. 같은 조회 기간 기준이며, 직원 사용량과 계정 전체 사용량을 함께 표시합니다. 공용·개인 필터는 이 분모를 바꾸지 않습니다.

기간별 분석표는 일별·주별·월별로 전환하며 한국 시간, 월요일 시작 주 기준입니다. 최근 24시간/7일/30일/90일/1년 범위의 전체 기록을 집계합니다. 분석표는 12행씩, 최근 기록은 최신 500건 범위에서 기본 25개씩 표시하며 25/50/100개와 페이지를 선택할 수 있습니다.
